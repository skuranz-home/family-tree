# The Nagle & Wiese Family Archive

An interactive family tree with the records behind every person: the 1894 Nagle family Bible, memorial cards, obituaries, letters and online records. It runs as a single web page (`index.html`) with no server, database or sign-in.

## What's in this folder

| File | What it is |
|---|---|
| `index.html` | The whole archive: tree, records, photos, map and research leads |
| `poster.pdf` | The printable poster |
| `apple-touch-icon.png`, `icon-192.png`, `icon-512.png`, `favicon.png` | Home-screen and browser icons |
| `manifest.webmanifest` | Lets phones add the site to the home screen like an app |
| `robots.txt` | Asks search engines not to index the site |
| `README.md` | This file |

## Put it online with GitHub Pages (about 10 minutes, free)

1. **Create a GitHub account** at <https://github.com/signup> if you don't have one.
2. **Create a repository.** Click **+** (top right) → **New repository**.
   - Name: for example `family-tree`. The site address will be `https://YOUR-USERNAME.github.io/family-tree/`.
   - Choose **Public**. Free GitHub Pages needs a public repository; see "Privacy" below.
   - Leave the other options alone and click **Create repository**.
3. **Upload the files.** On the new repository page, click **uploading an existing file**. Drag in every file from this folder (unzip it first), then click **Commit changes**.
4. **Turn on Pages.** Go to **Settings** → **Pages** (left menu). Under **Build and deployment**, set **Source** to **Deploy from a branch**, **Branch** to `main`, and folder to `/ (root)`. Click **Save**.
5. **Wait a minute or two**, then refresh the Pages settings screen. It shows "Your site is live at …". Open that link.

## Use it on an iPhone or iPad

Open the link in **Safari**. Then tap **Share** → **Add to Home Screen** to get a "Family Tree" icon that opens the archive full-screen. Pinch to zoom, drag to move, and tap a person to see their records.

## Updating it later

When there's a new version of `index.html` (or `poster.pdf`), open the repository → **Add file** → **Upload files**, and drag in the new file with the same name. It replaces the old one, and the site updates within a minute or two.

## Privacy

- Anyone with the link can view the site. It is not password-protected.
- `robots.txt` and a "noindex" tag ask search engines not to list it, so people find it only if someone shares the link.
- Because the repository is public, the files can also be browsed on GitHub by anyone who finds it.
- Living relatives appear by name only, with no dates or places. Some photographed handwritten notes still show birth dates in the handwriting.
- The "Full-size original in Google Drive" links open the originals in Google Drive. They work only for people your Drive sharing settings allow (for example "Anyone with the link → Viewer").
- To take the site down: **Settings** → **Pages** → **Unpublish**, or delete the repository.
